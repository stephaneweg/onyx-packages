# Onyx packages

The package repository of **Onyx**, the homemade operating system for the Raspberry Pi 4
(https://github.com/stephaneweg/onyx). Served by GitHub Pages at
https://stephaneweg.github.io/onyx-packages, read by Onyx's `pkg` command and its package manager.

- `index.txt` — every package: version, category, size, SHA-256, needs
- `index.sig` — the index's signature (ECDSA P-256 / SHA-256, DER in hex), checked on the Pi with the
  public key `SD:/etc/pkg/onyx.pub`
- `pkgs/<name>-<version>.opk` — the packages: ZIP archives of the card's tree plus `PKG/manifest.ini`
- `icons/<name>.bmp` — their icons

Everything here is generated by `tools/pkg/mkrepo.py` in the Onyx repository (docs/pkg/README.md):
do not edit it by hand — a changed index fails its signature on every card.
